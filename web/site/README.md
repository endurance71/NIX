# nix.shipapp.pl

Static website for NiX, served by Caddy on the ShipApp VPS from `/srv/nix-site`.

- `index.html` (PL) and `en/index.html` are generated by `npm run generate:site`. The scenes mirror the
  in-app welcome tour as CSS motion, so edit the copy in `scripts/generate-site.mjs` and the motion in `site.css`.
- `privacy/`, `terms/` and `support/` are generated by `npm run generate:legal-pages` from the same source as
  the app (`src/lib/legalDocuments.ts`).
- `npm run check:site` and `npm run check:legal-pages` fail when a generated page is stale.
- `img/` holds web-sized copies of the onboarding placeholders (`assets/onboarding/`, Unsplash License; see
  `assets/onboarding/CREDITS.md`). Replace both together when the final art lands.
- Local preview: the `nix-site` entry in `.claude/launch.json` (`python3 -m http.server 4173 --directory web/site`).
